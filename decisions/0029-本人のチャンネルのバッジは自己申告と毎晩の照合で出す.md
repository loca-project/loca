# 0029. 本人のチャンネルのバッジは、自己申告のチャンネルと毎晩の照合で出す

- 状態: 採用
- 日付: 2026-09-25
- 関連: [0017](0017-YouTube-Data-APIとFirestoreへの書き込みはActionsから行う.md)、[0019](0019-プロフィールはニックネームと同意だけを持つ.md)、T55

## 背景

投稿者が自分の YouTube チャンネルの動画を載せていることを、閲覧者に分かるようにしたい（撮影者本人への見返り。ADR 0016）。
本人確認に YouTube の OAuth（`youtube.readonly`）を使うと、Google の審査と同意画面の追加が要る。

## 決定

1. **本人確認はしない。自己申告にする**（利用者の判断。2026-09-24）。画面にも「自己申告」と出す。
2. 投稿者はプロフィールで自分のチャンネルの URL を登録する。受け付けるのは `youtube.com/channel/UC…`（チャンネル ID）と
   `youtube.com/@ハンドル` の 2 つの形だけ。`users/{uid}.channel` に `UC…` か `@ハンドル` で保存する（本人だけが書ける。消すこともできる）。
3. **照合は毎晩の YouTube の情報の更新（Actions。ADR 0017）が行う。** 動画のチャンネル ID（`videos.list` の `snippet.channelId`）と、
   投稿者の `channel`（ハンドルは `channels.list` の `forHandle` で ID に直す）が一致したら、マーカーの `youtube.ownChannel` を `true` にする。
   `youtube` 項目は Actions だけが書けるので、利用者が印を自分で付けることはできない。
4. `youtube.channelId` と `youtube.ownChannel` は公開データに載るので、バッジは読み取りを増やさずに誰にでも出る。
   チャンネルを登録・変更してから、バッジに反映されるまでは次の毎晩の更新（登録直後の動画は毎時の更新）まで待つ。

## 検討した代替案

- **YouTube の OAuth で本人確認する**: 審査と同意画面の追加が要る。利用者の判断で見送り。
- **ブラウザで照合する**: `users/{uid}` はログインした人しか読めず（ADR 0019）、未ログインの閲覧者にバッジを出せない。却下。

## 結果

- 他人のチャンネルを自分のものとして登録できてしまう。バッジは「自己申告」と明記し、本人の保証ではないことを示す。
- ハンドルを ID に直すため、毎晩の更新で登録したハンドルの数だけ YouTube API を 1 ユニットずつ使う。
- 毎晩・毎時の更新で、対象のマーカーの投稿者の人数分だけ `users` を読む（全件は読まない。Firestore の無料枠に数える）。

## 確かめ方

チャンネルを登録した投稿者の、そのチャンネルの動画だけに、毎晩の更新のあとでバッジが出る（別のチャンネルの動画には出ない）。
