# 0026. サイト名 Loca の書体は Fraunces にし、4 文字だけを自前で置く

- 状態: 採用
- 日付: 2026-09-25
- 関連: T76（サイドメニューを開いたときにサイト名を出す）、T78（書体の決定）、T77（見出しの並べ方）、T79（実装）

## 背景

サイト名を覚えてもらうため、サイドメニューを開いたときだけ上部に「Loca」を出す（T76）。
常設のタイトルバーは地図の操作の場所を狭めるので置かない。文字をただ置くのではなく、サイトに合う書体を選ぶ。

選び方は利用者と決めた 2 段階で行った（見本は実際のサイドメニューと同じ幅の白いパネルに組んだもの）。

| 回 | 出した案 | 選ばれた案 |
|---|---|---|
| 1 回目 | 方向のまったく違う 10 案（やわらかな明朝・幅広ゴシック・筆記体・等幅・高級誌のイタリック・丸ゴシック・ステンシル・レトロ・ドット文字・ポスター体） | 案 1 やわらかな明朝（Fraunces。「やわらかく、スタイリッシュ」） |
| 2 回目 | 案 1 の方向で 5 案（Fraunces の細身・Fraunces の斜体・Young Serif・Instrument Serif・Gloock） | 案 A Fraunces の細身 |

## 決定

1. **書体は Fraunces**（Undercase Type ほか）。可変の軸を次に固定する。

   | 軸 | 値 | 意味 |
   |---|---|---|
   | `wght` | 600（SemiBold） | 1 回目の 700 より一段細く |
   | `SOFT` | 100 | 角を最大まで丸める（やわらかさ） |
   | `WONK` | 0 | a・c などの癖のある字形を使わない（落ち着き） |
   | `opsz` | 24 | 表示する大きさ（24px。ADR 0027）に固定。見本のブラウザの自動の光学サイズと同じ形 |

   字間は `-0.01em`。
2. **使う 4 文字（L・o・c・a）だけに絞った woff2 を、ソースに置いて CSS に埋め込む。**
   Google Fonts の `text=` が空白（U+0020）を 1 つ足すので、中身は L・o・c・a と空白の 5 文字。
   ファイルは `src/assets/fonts/fraunces-loca.woff2`（1,348 バイト。静的で、可変の表 `fvar`・`gvar` が無い。2026-09-25 に取得）。
   4 kB 未満なので Vite が CSS に埋め込み、書体のための別の通信が起きない。取得の手順は同じ場所の README。
3. **Google Fonts から実行時に読まない。** 外部サービスへの依存を減らすこのプロジェクトのねらい（ADR 0010・0011）に合わせる。
   閲覧者の IP アドレスが Google に送られることも避ける。
4. **ライセンスは SIL Open Font License 1.1。** 予約フォント名が無いので、絞ったファイルも「Fraunces」の名前のまま使える。
   条文 `OFL.txt` を書体ファイルと同じ場所に置き、公開する CSS には著作権とライセンスの注記（`/*! … */`）を残す。
5. 読み込みは `@font-face`（名前 `Loca Wordmark`、`font-display: swap`）。代わりの書体は `Georgia, serif`。
6. 色・大きさ・メニュー名との並べ方は [ADR 0027](0027-サイドメニューの上部はサイト名とメニュー名を1行に並べる.md)（紺 `loca-700`・24px）。

## 採らなかったもの

| 案 | 採らなかった理由 |
|---|---|
| 1 回目の案 1 そのまま（`wght` 700・`WONK` 1） | 利用者が 2 回目で、癖を抜いた細身の案 A を選んだ |
| Google Fonts の CSS を読む | 外部への依存が 1 つ増える。4 文字なら自前で置いても 1.3 kB で済む |
| `public/fonts/` に置き `<link rel="preload">` で読む（決めた当初の案） | 1.3 kB なら CSS に埋め込むほうが通信が 1 回少なく、開いた瞬間に代わりの書体が見えることも無い |
| 可変のまま置く | 全文字の可変フォントは 67,304 バイト。軸を固定した 4 文字なら 1,348 バイト |
| 書体ファイルを置かず、文字を SVG の画像にする | 文字として読めなくなる（検索・読み上げ）。言語の切り替えや色の変更のたびに画像を作り直すことになる |

## 確かめ方

- 静的かどうかは woff2 の表の一覧で確かめた（取得したファイルは 15 表で `fvar` なし。対照の可変フォントは 20 表で `fvar`・`gvar` あり）。
- 書体が読み込まれ、サイドメニューに出ることは T79 の `/ui-check`（`document.fonts.load` と画面の写真）で確かめた。
- Google Fonts は User-Agent を付けないと woff2 ではなく TrueType を返す（決めた当初の 2.5 kB はこれを測っていた）。
