# 0026. サイト名 Loca の書体は Fraunces にし、4 文字だけを自前で置く

- 状態: 採用
- 日付: 2026-09-25
- 関連: T76（サイドメニューを開いたときにサイト名を出す）、T77（見出しの並べ方）、T79（実装）

## 背景

サイト名を覚えてもらうため、サイドメニューを開いたときだけ上部に「Loca」を出す（T76）。
常設のタイトルバーは地図の操作の場所を狭めるので置かない。文字をただ置くのではなく、サイトに合う書体を選ぶ。

選び方は利用者と決めた 2 段階で行った（見本は実際のサイドメニューと同じ幅の白いパネルに組んだもの）。

| 回 | 出した案 | 選ばれた案 |
|---|---|---|
| 1 回目 | 方向のまったく違う 10 案（やわらかな明朝・幅広ゴシック・筆記体・等幅・高級誌のイタリック・丸ゴシック・ステンシル・レトロ・ドット文字・ポスター体） | 案 1 やわらかな明朝（Fraunces。「やわらかく、スタイリッシュ」） |
| 2 回目 | 案 1 の方向で 5 案（Fraunces の細身・Fraunces の斜体・Young Serif・Instrument Serif・Gloock） | 案 A Fraunces の細身 |

## 決定

1. **書体は Fraunces**（Undercase Type ほか）。可変の軸を次に固定する。

   | 軸 | 値 | 意味 |
   |---|---|---|
   | `wght` | 600（SemiBold） | 1 回目の 700 より一段細く |
   | `SOFT` | 100 | 角を最大まで丸める（やわらかさ） |
   | `WONK` | 0 | a・c などの癖のある字形を使わない（落ち着き） |
   | `opsz` | 表示する大きさ（px）に合わせる | 見本と同じ、ブラウザの自動の光学サイズ |

   字間は `-0.01em`。
2. **使う 4 文字（L・o・c・a）だけに絞ったファイルを自前で置く。** 置き場所は `public/fonts/`、形式は woff2。
   大きさは約 2.5 kB（Google Fonts の `text=Loca` で 2 通りの軸指定を取得し、2,464・2,480 バイト。2026-09-25）。
   初期読み込みの JS の上限（260 kB）には入らない。
3. **Google Fonts から実行時に読まない。** 外部サービスへの依存を減らすこのプロジェクトのねらい（ADR 0010・0011）に合わせる。
   閲覧者の IP アドレスが Google に送られることも避ける。
4. **ライセンスは SIL Open Font License 1.1。** 予約フォント名が無いので、絞ったファイルも「Fraunces」の名前のまま使える。
   条文 `OFL.txt` を書体ファイルと同じ場所に置く（OFL の条件）。
5. 読み込みは `@font-face` の `font-display: swap`。代わりの書体は `Georgia, serif`。
   ページを開いた時点でサイドメニューが開いていることがあるので、`<link rel="preload">` で先に読む。
6. 色・大きさ・メニュー名との並べ方は [ADR 0027](0027-サイドメニューの上部はサイト名とメニュー名を1行に並べる.md)（紺 `loca-700`・24px）。

## 採らなかったもの

| 案 | 採らなかった理由 |
|---|---|
| 1 回目の案 1 そのまま（`wght` 700・`WONK` 1） | 利用者が 2 回目で、癖を抜いた細身の案 A を選んだ |
| Google Fonts の CSS を読む | 外部への依存が 1 つ増える。4 文字なら自前で置いても 2.5 kB で済む |
| 書体ファイルを置かず、文字を SVG の画像にする | 文字として読めなくなる（検索・読み上げ）。言語の切り替えや色の変更のたびに画像を作り直すことになる |

## 確かめ方

- 取得元と軸の値は、`public/fonts/` の README に書く（実装は T79）。取得した woff2 が L・o・c・a の 4 文字だけを含むこと、
  `WONK` 0 の形（a の上の癖が無い）で出ることは、T79 の `/ui-check` の画面で確かめる。
- 未確認: Google Fonts の `text=` で返るファイルが軸を固定した静的なものか可変のままか。T79 で取得するときに確かめ、
  可変でなければ `opsz` を表示する大きさに固定した値で取得する。
