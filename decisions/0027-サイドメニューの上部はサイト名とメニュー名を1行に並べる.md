# 0027. サイドメニューの上部は、サイト名とメニュー名を開閉ボタンの横に 1 行で並べる

- 状態: 採用
- 日付: 2026-09-25
- 関連: [0026](0026-サイト名Locaの書体はFrauncesを4文字だけ自前で置く.md)、T76（サイト名を出す）、T77（並べ方の決定）、T79（実装）

## 背景

サイト名を覚えてもらうため、サイドメニューを開いたときだけ上部に「Loca」を出す（T76）。
常設のタイトルバーは地図の操作の場所を狭めるので置かない。今の各メニューの見出し（「地図検索」など）は残す。

今の上部は、パネル（幅 288px）の見出し 1 行（12px の太字、高さ 41px）だけ。左のアイコン列（幅 56px）の一番上に開閉ボタン ☰（44px、上から 12px）がある。

### 調べた事例（2026-09-25）

| 事例 | 分かったこと | 出典 |
|---|---|---|
| Material 3 Expressive（2025 年 5 月） | 引き出し型のメニューを非推奨にし、アイコン列を開いて広げる形に置き換えた | [9to5Google](https://9to5google.com/2025/05/14/material-3-expressive-navigation/) |
| Material の Android 実装 | アイコン列の上端に、ロゴや主要ボタンを固定する枠（header）がある | [NavigationRail.md](https://github.com/material-components/material-components-android/blob/master/docs/components/NavigationRail.md) |
| Material 3 のアイコン列の指針 | 上端にロゴを置いてよいが、ボタンと見間違えるロゴを避け、ロゴを開閉ボタンにしない | [m3.material.io](https://m3.material.io/components/navigation-rail/guidelines)（本文は取得できず、検索結果の要約で確認） |
| ChatGPT・Claude・Gemini の Web 版 | 左の一覧を開くと開閉ボタンの横にサービス名が出て、閉じるとアイコンだけになる | 出典なし（知識による。未確認） |
| SaaS のパンくず | 上位の名前と今いる場所を 1 行に並べ、階層と現在地を同時に示す | [Smashing Magazine](https://www.smashingmagazine.com/2022/04/breadcrumbs-ux-design/)・[Eleken](https://www.eleken.co/blog-posts/breadcrumbs-ux) |

### 比べた案（実寸の見本で利用者が選んだ）

| 案 | 形 | 上部の高さ | 今との差 |
|---|---|---|---|
| **B** | 開閉ボタンの横に「Loca │ メニュー名」を 1 行 | 56px | +15px |
| A | 1 段目に Loca、2 段目にメニュー名 | 83px | +42px |
| C | 小さめの 2 段（開閉ボタンの高さとそろわない） | 61px | +20px |

## 決定

B を採る。

1. **上部の高さは 56px。** 上に 12px の余白、その下に 44px の行（下の区切り線 1px を含む）。
   行の中心は上から 33.5px で、開閉ボタンの中心（34px）とそろう。
2. **行の中身は左から「Loca」・区切り線・メニュー名。** 間は 10px。
   | 要素 | 指定 |
   |---|---|
   | Loca | Fraunces（ADR 0026）24px、紺 `loca-700`（`#184c93`）。押せない文字にする（リンク・ボタンにしない） |
   | 区切り線 | 幅 1px・高さ 18px・`gray-300` |
   | メニュー名 | 今と同じ 12px 太字 `gray-700`。収まらなければ末尾を「…」で切る。見出し（`h2`）は今のままメニュー名が持つ |
3. **サイドメニューを閉じると見えなくなる**（今のパネルの開閉のまま。常設のタイトルバーは作らない）。
4. 日本語と英語で同じ形。PC では、いちばん長いメニュー名（撮影リクエストランキング・Shooting request ranking）も 1 行に収まる。
   スマホでは右上のログインボタンがパネルの上部に重なるので、右の余白を `max(1rem, calc(460px - 100vw))` に広げ、
   長いメニュー名は「…」で切る（375px で「撮影リクエストランキ…」）。
5. 上部が 15px 高くなる影響は、T79 で次のとおり洗い出した（`src` に 41px などの固定値は 0 件）。

   | 高さに依存しうるもの | 結果 |
   |---|---|
   | パネルの中身（スクロールする範囲） | 中身は残りの高さで伸び縮みする。低い画面（420px）でもスクロールで最後のボタンまで届く |
   | 投稿フォーム・撮影リクエストの下端のボタン | パネルの中身と一緒にスクロールする。固定の位置を持たない |
   | 共通結果パネル・地図フィルター | 位置はパネルの幅（288px）だけで決まり、高さに依存しない |
   | アイコン列（TabRail） | 高さは画面いっぱいのまま。開閉ボタンの中心（34px）と上部の行の中心（33.5px）がそろう |
   | スマホの右上のログインボタン | 上部に重なるので、右の余白を広げた（決定 4） |

## 採らなかったもの

| 案 | 理由 |
|---|---|
| A（2 段） | サイト名は最も目立つが、中身が 42px 下がる。スマホで投稿フォームなどの見える範囲が減る |
| C（小さめの 2 段） | 中身が 20px 下がるうえ、Loca が開閉ボタンと横にそろわない |
| アイコン列の一番上にロゴを置く | アイコン列は閉じても出ているので、「開いたときだけ出す」に反する。指針のとおり、ロゴを開閉ボタンにもしない |

## 確かめ方

T79 の `/ui-check` で次を確かめた（13 / 13 件 OK、2026-09-25）。

- 書体 `Loca Wordmark` が読み込まれる。
- 6 つのメニューすべてで上部が 56px。「Loca │ メニュー名」の中心は 33.5px で、開閉ボタン（34px）との差は 0.5px。
- PC では、日本語と英語のいちばん長いメニュー名が 1 行に収まる。
- スマホ（375px・360px）では、メニュー名が「…」で切れ、ログインボタンと重ならない。
- 低い画面（420px）で、パネルの中身がスクロールして最後のボタンまで届く。
- パネルを閉じると Loca が見えない（幅 0 に右の枠線 1px・透明度 0）。
