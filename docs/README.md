# docs/

仕様書・設計ドキュメントを置きます。**常時読み込まれません**。
Claude には必要なときにファイルを指定して読ませます。

## 置くもの

- 機能仕様、画面仕様
- データモデル、スキーマ定義
- API 仕様
- 運用手順、デプロイ手順

## 置かないもの

| 内容 | 正しい置き場所 |
|---|---|
| 毎回知っておいてほしい前提 | `project/context/` |
| なぜその設計にしたかの記録 | `project/decisions/` |
| 繰り返す作業手順（`/名前` で呼びたい） | `.claude/skills/` |
| コーディング規約 | `.claude/rules/` |

## 命名

`NN-主題.md` の形で並び順を制御すると、一覧したときに読む順序が分かります。
