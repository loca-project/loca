# Loca 要件定義 (5) 管理者モード

> 移植元: Loca システム要件定義書 5章。

## 5. 管理者モード関連機能 (新規追加・変更)

### 5.1. 管理者モードへのアクセス
* **トリガー**: Google認証アイコンクリック時のポップアップに表示される「**管理者モード**」ボタンを押下。
* **画面表示**: 画面中央に管理者モード専用の画面をオーバーレイで表示する。
* **画面構成**:
    * 画面上部に**タブ形式のナビゲーション**を配置し、各機能画面を切り替えられるようにする。
    * 各機能画面は、タブをクリックした際に切り替わり、他の画面のデータは非表示となる。
    * タブの配置順は以下の通りとする。
        1.  📊 統計分析（Statistics）
        2.  📤 データエクスポート（Data Export）
        3.  📜 ログ一覧（Marker Logs）
        4.  🛠️ **ユーザー管理**
        5.  🛠️ **マーカー管理**

### 5.2. 管理者モードの機能タブ

#### 5.2.1. 📊 統計分析（Statistics）
* **機能**: Youtubeの投稿日をもとに期間を指定し、マーカーの登録情報の統計を表示する。
* **表示対象**: **タグ**（映っているもの、雰囲気、撮影の季節、撮影の時間帯、撮り方。要件 3.3）、**撮影機器**（メーカー、シリーズ、モデル）などの登録されたマーカーの統計情報。
* **期間指定**: 統計を集計する期間（例：〇年〇月～〇年〇月）を指定するためのUI（日付ピッカーなど）を提供する。
* **表示形式**: 統計情報は、グラフ（例：円グラフ、棒グラフ）や集計表（件数）などで視覚的に分かりやすく表示する。

#### 5.2.2. 📤 データエクスポート（Data Export）
* **機能**: 登録されているマーカー情報の一部をデータセットとしてエクスポートする。
* **エクスポート対象データ**:
    * マーカーの**Youtube URL**
    * **タグ**（映っているもの、雰囲気、撮影の季節、撮影の時間帯、撮り方）。値は要件 3.3 のキーで出す
    * **現地メモ**
* **エクスポート形式**: CSVまたはJSON形式でのファイルダウンロード機能とする。
* **データ範囲**: すべての登録済みマーカーデータ（論理削除されたものは除く）を対象とする。

#### 5.2.3. 📜 ログ一覧（Marker Logs）
* **機能**: マーカーの登録および更新に関するログを一覧表示する。
* **表示項目**:
    * マーカーの**登録日**
    * マーカーの**編集などの更新日**
    * その他、ログとして有用な情報（例：マーカーID、操作ユーザーIDなど）。
* **表示形式**: 日時順（降順）のテーブル形式で表示し、必要に応じてソートやフィルタリング機能を実装する。

#### 5.2.4. 🛠️ ユーザー管理（User Management）
* **機能**: サイトに登録されたユーザー情報の管理およびアクセス制御を行う。
* **データベース同期**: ユーザー情報と**Firestore**のデータは常に**同期が取れた状態**を保証する。
* **最新情報取得のための強制同期ボタン**: 同期エラー時などに備え、「ユーザー管理」タブ内に**「ユーザー情報の取得」ボタン**を実装する。ボタン押下で**Firestoreから強制的に最新情報を取得**し、画面表示およびプロフィールを管理する関連ファイルも最新の状態に更新する。
* **画面構成**: 以下の4つのセクションを**横並び**で**一画面**に表示する。すべてのセクションで**Google IDとGoogle表示名**は**必須かつ併記**して表示する。

| セクション名 | 対象ユーザー | Google ID | Google表示名 | その他の表示項目 | 操作ボタン |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **管理者ユーザー** | 管理者権限を持つユーザー | 必須 | 必須 | - | - |
| **現在のユーザー一覧** | サイトに登録済みの一般ユーザー | 必須 | 必須 | **登録日** | 手動での**削除**、**要注意ユーザー**への移動、**ブラックリスト**への移動 |
| **要注意ユーザー** | 「現在のユーザー一覧」から手動で**削除された履歴**を持つユーザー | 必須 | 必須 | - | **登録解除**（リストから削除） |
| **ブラックリスト** | 「要注意ユーザー」から**指定・登録**されたユーザー | 必須 | 必須 | - | **登録解除**（リストから削除） |

* **ブラックリスト機能の挙動**:
    * 「ブラックリスト」に登録されているユーザーがGoogle認証を試みた場合、**プロフィール登録画面を表示する前**にログインを不可とする。
    * ユーザーに対して「登録が制御されています」という旨の**ポップアップメッセージ**を表示する。
* **ユーザー削除時の挙動**: ユーザーの削除が行われた場合、**Firestoreからも該当データが完全に削除**されるように実装する。

#### 5.2.5. 🛠️ マーカー管理（Marker Management）
* **機能**: 特定のGoogleアカウントに紐づくマーカーの一覧表示、選択削除、地図へのジャンプ機能を提供する。（旧 `5.2.4. ユーザー別管理` からマーカー管理機能を分離）
* **ユーザー指定**: **Googleアカウント（メールアドレスなど）を指定**するための検索/入力フィールドを画面上部に配置する。
* **一覧表示**: 指定されたGoogleアカウントが登録した**すべてのマーカー情報**を一覧で表示する。
* **操作機能**:
    * **選択形式**: マーカー一覧に**チェックボックス**を配置し、複数選択を可能とする。
    * **削除機能**: 選択されたマーカーを一括で削除するボタンを配置する。この削除は、`1.4. マーカーデータ読み込みのリアルタイム・ハイブリッド化`で定義された**論理削除（Soft Delete）**として実行される。
    * **地図へのジャンプ機能**:
        * **単一選択時**: 選択されているマーカーが**1つのみ**の場合、**「地図へジャンプ」ボタン**を**活性化**する。ボタンを押下すると、そのマーカーを地図の中心に表示し、適切な縮尺にズームする（`3.6.` に準拠）。
        * **複数選択時・未選択時**: 選択されているマーカーが**2つ以上**または**0件**の場合、**「地図へジャンプ」ボタン**は**非活性化（グレーアウト）**する。

## Loca での扱い（移植時の差分）

タブ構成は要件の 5 つに加え、移植元の実装にあった機能を整理して 9 タブにした。

| タブ | 要件 | 状態 |
|---|---|---|
| 統計分析 | 5.2.1 | 移植済み |
| データエクスポート | 5.2.2 | 移植済み（CSV / JSON） |
| ログ一覧 | 5.2.3 | 移植済み |
| ユーザー管理 | 5.2.4 | 移植済み（4 区画・横並び） |
| マーカー管理 | 5.2.5 | 移植済み |
| 通報一覧 | 3.8 の受け皿 | 追加 |
| 機器マスタ | 1.2「ソース編集なしで更新可能」 | 追加 |
| アクセス制限 | 1.3 の台帳 | 追加（**遮断自体は未実装**） |
| バックアップ | 移植元の実装にあり | 追加 |

- **Firestore への依存はない**。すべて `DataPort` 越しに動くため、ローカルアダプタでも管理者モードを操作できる。
- **ブラックリストの挙動**: プロフィール購読時に `status === 'blacklisted'` を検出したら
  プロフィール画面を出さずにサインアウトし、メッセージを表示する（`src/shared/hooks/useSession.ts`）。
- **管理者の判定**: プロフィールの `isAdmin`、または `VITE_ADMIN_EMAILS` に一致するメールアドレス。
  移植元はメールアドレスをソースに直書きしていたが、環境変数に移した。

統計分析（5.2.1）とデータエクスポート（5.2.2）は、ログインを持たなかった間（2026-09-22〜）は誰でも開ける公開の機能だった。
