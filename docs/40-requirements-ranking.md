# Loca 要件定義 (4) ランキング関連機能

> 移植元: Loca システム要件定義書 4章。

## 4. ランキング関連機能

### 4.1. 共通仕様
* **適用範囲**: 本セクション（ランキング関連機能）の仕様は、マーカー検索機能には適用しない。
* **デフォルト表示**: フィルタなし、Youtube再生数順（降順）、データは1日1回の定時更新後のものを使用。
* **データ取得ロジック**:
    * **フィルタなし**: 定時更新された基本データ（最大100件）はサーバー側でキャッシュ済み。
    * **フィルタ適用時**: サーバー負荷回避のため、クライアントサイドでキャッシュ済み基本データ（最大100件）に対して再集計を行う。
    * **ページネーション**: 100件以上のデータを見る場合は、サーバーへ新規リクエストを行い、100件ずつ表示する。
* **フィルタ適用時の制限**:
    * フィルタ適用中に表示件数が100件未満の場合、ページネーション（「もっと見る」等）は非表示/無効化する。
    * 以下のメッセージを一覧下部に表示する：「現在、フィルタが適用されているため、表示は最大100件に制限されています」
* **表示形式**: Youtube URLは列幅節約のため、すべて **"Link"** というハイパーリンクで表示する。
* **結果表示エリア**:
    * 各種ランキングの集計結果は、地図上の**「共通結果パネル（オーバーレイ）」**に表示する。
    * サイドメニューの開閉に連動して表示位置が移動し、右上の「閉じるボタン」で非表示化可能。

### 4.2. 共通フィルタ項目
* **UI配置**: 共通フィルタと個別フィルタは、スマートフォンでもタップしやすいように**縦一列**で配置する。
* **実行アクション**:
    * フィルタ項目の変更だけでは集計を実行しない。
    * 項目群の最下部に配置する**「適用」ボタン**（または「検索」ボタン）を押下したタイミングでフィルタリングを実行し、結果パネルを表示・更新する。
    * **UI挙動（モバイル）**: スマートフォン（モバイルビュー）での操作時、**適用ボタンを押下したタイミングでサイドメニューを自動的に閉じる（非表示にする）**。
* **動画投稿日**: 全期間, 1年以内, 半年以内, 3ヶ月以内, 1ヶ月以内, 2週間以内, 当日
* **動画の長さ**: すべて, 4分未満, 4分以上20分未満, 20分以上
* **感情タグ（新規追加・複数選択可）**:
    * **UI配置**: **動画の長さ**フィルタの下に、以下の3カテゴリを縦一列で追加する。
    * **選択形式**: 複数選択が可能な**チェックボックス形式**（またはマルチセレクト）で実装する。
    * **フィルタロジック**: 選択されたタグは**OR条件**で抽出する。
    
| UI配置順 | 大カテゴリ | 選択肢（タグ） |
| :--- | :--- | :--- |
| **1** | **行動への影響 (Actionable Intent)** | 訪問/地域紹介, 映像制作, お祭り/イベント, 機器/技術紹介 |
| **2** | **動画の雰囲気 (Atmosphere/Vibe)** | 明るい(Positive), 真面目(Serious), 落ち着いた, 緊張, 幻想的, スマート |
| **3** | **感情の核 (Core Emotion)** | 喜び, 興奮, 癒し, 驚き, 恐怖, 悲しみ, 希望 |

* **表示件数**: 30, 20, 10
* ※クライアント保持の最大100件に対し、さらに絞り込むUI機能として動作させる。

### 4.3. 個別ランキング仕様
* **地域別ランキング**:
    * 都道府県フィルタ: プルダウン選択、登録された都道府県情報をもとに集計。
    * 季節フィルタ: Youtube投稿日をもとに集計（1月-3月, 4月-6月, 7月-9月, 10月-12月）。
* **チャネルランキング**:
    * チャンネル名が同じマーカーの動画件数と再生数を合算し、再生数順で表示。
* **機器別ランキング**:
    * **フィルタ項目**: **メーカー**、**シリーズ**、**モデル**の3項目を独立したプルダウンとして実装する。
    * **フィルタ実行の条件**:
        * **いずれかの項目が選択されていれば**、その条件でフィルタリングを実行する。
        * **未選択の項目**はフィルタ対象外（すべての値を含む）として扱うことで、単一項目だけのフィルタリング（例: メーカーのみ）を可能とする。
    * **UI連動制御**:
        * **初期状態**: すべてのプルダウンは「すべて」または「未選択」で初期化される。
        * **連動とグレーアウト**:
            * **メーカー**が「すべて」/「未選択」の場合、**シリーズ**と**モデル**のプルダウンは**グレーアウト（無効化）**する。
            * **メーカー**が選択されると、**シリーズ**のプルダウンには、そのメーカーに紐づく値のみが表示される。
            * **シリーズ**が選択されると、**モデル**のプルダウンには、そのメーカーとシリーズに紐づく値のみが表示される。
    * **デザイン**: **青色の強調デザイン**を適用し、タップしやすい縦一列の配置とする。
    * **表示順**: 登録情報をもとにフィルタし、再生数順で表示する。

### 4.4. ランキング結果からの地図ジャンプ機能

ランキングタブ（地域別、チャネル、機器別）のフィルタ実行後に表示される**共通結果パネル**内のレコード一覧に対し、以下の地図ジャンプ機能を実装する。この機能は、上記 `3.6.` の動作ロジックに準拠する。

* **UI要素**:
    * 一覧の各レコードの行内に、地図へのジャンプを実行するための**小さいアイコン**（例：地図ピンアイコンなど）を配置する。
    * また、結果パネルの下部または上部に、複数の選択状態を制御するための**「地図へジャンプ」ボタン（仮称）**を配置する。
* **単一レコードからのジャンプ機能（アイコン操作）**:
    * **トリガー**: 各レコード行に配置された**小さいアイコン**をクリックまたはタップした時。
    * **アクション**:
        1.  地図画面に遷移し、選択されたレコードに対応するマーカーの位置が、地図の中心となるように移動（パン）させる。
        2.  マーカーが明確に視認できる**適切な縮尺サイズ**（例：ズームレベル14～16程度）に自動的に調整（ズーム）する。
        * ※このアイコン操作は、一覧でのチェックボックス選択状態にかかわらず、常に単一マーカーへのジャンプを実行する。
* **複数選択時のUIボタン制御（一括操作）**:
    * **機能の目的**: 複数のマーカーを選択した際の挙動を一律で制御する。
    * **動作**: `3.6. ユーザーマーカー一覧画面からの地図ジャンプ機能` の「UIボタンの制御」と同様に実装する。
        * **単一選択時**: ボタン**活性化**。押下時の動作はアイコン操作と同様。
        * **複数選択時・未選択時**: ボタン**非活性化（グレーアウト）**。

## Loca での扱い（2026-09-22 の構成確定による変更）

Google API を使わない決定により、**再生数・動画投稿日・再生時間は取得できない**
（YouTube oEmbed が返すのは タイトル / チャンネル / サムネイル のみ）。
本章の基準を Loca 内の指標に置き換えた。判断の経緯は
[0006-ランキング基準をLoca内の指標に変える.md](../decisions/0006-ランキング基準をLoca内の指標に変える.md)。

| 本章の記述 | 現在の実装 |
|---|---|
| 4.1 再生数順（降順） | 登録件数の降順（同数なら新しい順） |
| 4.2 動画投稿日フィルタ | **Loca への登録日**フィルタ（選択肢は同じ） |
| 4.2 動画の長さフィルタ | **削除** |
| 4.3 地域別＝再生数順 | 都道府県ごとの**登録件数**順 |
| 4.3 チャネル＝再生数合算 | チャンネルごとの**登録本数**順 |
| 4.3 機器別＝再生数順 | 機器の組み合わせごとの**登録件数**順 |
| 4.3 季節フィルタ（投稿日） | **登録した四半期**フィルタ |
| 4.1 100 件上限・ページネーション | 上限のみ維持。ページネーションは未実装 |

感情タグフィルタ（OR 条件）、表示件数（30/20/10）、共通結果パネル、
地図ジャンプ（4.4）は要件どおり維持している。
