# plans/

計画とタスク分解を置きます。`/loop` の既定プロンプト（`.claude/loop.md`）は、
他にやることが無いときここを見に行きます。

## 使い方

1つの取り組みにつき1ファイル。`NN-主題.md` で並べます。

```markdown
# ユーザー認証の実装

## ゴール
（完了条件を検証可能な形で書く。「テストが通る」「〜が表示される」など）

## タスク
- [ ] 手順1
- [ ] 手順2

## 未決事項
- （判断待ちのこと。決まったら ADR に移す）
```

## /goal との連携

完了条件が機械的に検証できるなら、`/goal` に渡すと Claude が条件を満たすまで自走します。

```
/goal project/plans/01-認証.md のタスクがすべて完了し、npm test が通る
```

終わった計画はファイルごと削除するか、`## 状態: 完了` を先頭に足して残します。
