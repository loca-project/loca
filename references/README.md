# references/

外部資料の調査メモを置きます。Claude に何度も同じ Web 検索をさせないための保管場所です。

## 置くとよいもの

- ライブラリの使い方を調べた結果（バージョンと調査日を必ず書く）
- 外部 API のエンドポイント一覧とレスポンス例
- 仕様書・RFC の該当箇所の抜粋
- トラブルシューティングで判明した原因と対処

## 書式

各ファイルの先頭に出典と鮮度を書いてください。古い情報を根拠にされるのを防ぎます。

```markdown
# ○○ライブラリ v3 の使い方

- 出典: https://example.com/docs
- 調査日: 2026-09-22
- 対象バージョン: 3.2.1
```

## 注意

ここに書いた内容は**調査時点のスナップショット**です。Claude が参照する前に、
バージョンや API が変わっていないか確認させてください。
